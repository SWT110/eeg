# D 版层数与分段位置改为命令配置

用户将三分支总层数从 4/10/16 调整为 2/5/8，确认前后段分别为 1+1、2+3、4+4；因此新默认在第 1/2/4 个 Block 后融合通道。将总层数和分段位置分别开放为 `--transformer-depths` 与 `--split-after-blocks`，省略分段位置时按各总层数的一半向下取整，避免以后更换层数都要改源码。仍固定为三个非空的双段编码器，QKV、Branch Loss、类别权重扫描及其余超参数沿用 ADR-0004。

实际层数、分段位置、跳接目标写入实验计划和模型配置，恢复模型时读取所存配置，支持重建原 4/10/16 模型。不同结构使用独立 outputs 母目录；旧代码生成的训练断点仍按原代码版本续训，不因参数化而放宽数据、代码哈希与配置校验。
