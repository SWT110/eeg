# 通道保留结构采用 4/10/16 三分支与 D 完整版

用户确认将单条 depth10 通道保留编码器扩展为 depth4、depth10、depth16 三个独立并行编码器；Time 与 FFT 各自使用一套，域内共享 PatchEmbedding 输出，编码器参数不共享。每条分支分别在第 2、5、8 个 Block 后完成 21→1 通道融合，继续保留入口 21→21 特征对前半段每个 Block 的固定跳接，以及半程融合特征对后半段每个 Block 的固定跳接。

三个完整编码器的输出先分别在 Time 域内、FFT 域内进行 Cross-Depth QKV 交互，再按相同深度配对 Time/FFT 特征，送入三个独立分类头。采用旧版 Branch Loss：以可学习 softmax 分支权重加权三个分支的交叉熵，再加 0.2 倍的分支交叉熵均值；推理使用同一组分支权重融合 logits。该目标不额外包含融合 logits 的交叉熵。这样先复用已有交互与监督机制，避免同时重设计融合目标，使后续对照难以解释。

类别损失权重按 e_1/e_2/e_3 顺序传给各分支交叉熵，与三个深度分支的融合权重分别记录。除上述结构与分支监督配置外，沿用此前确认的仓库本地默认、seed 42、排除 S6/S17 的 15 人正式队列及 ADR-0002/0003 的评估约定。QKV dropout 使用本地默认 0.1，不沿用旧最佳实验覆盖的 0.25。

用户选择自行指定类别权重候选，支持用 `3,2,1|3,3,1` 一次提交多个候选，按输入顺序完整训练一组再训练下一组。每组结果独立保存到同一个 outputs 母目录下，两张 GPU 可分别训练互不重复的候选批次。程序汇总准确率、受试者等权 Macro-F1、逐类召回率及逐受试者较低召回率，最终由用户选择，不自动宣布冠军。旧 11 人结构的权重成绩不作为本结构的最优结果，S6/S17 不参与类别权重选择。
