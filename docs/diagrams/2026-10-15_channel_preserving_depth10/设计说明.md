# 保留电极通道的双域 EEG-Conformer：录音理解与重绘

核心修改是把电极通道融合推迟到第 5 个 Encoder Block 之后：Time 和 FFT 两路各保留一条 10 层链，前 5 层逐电极做序列建模，同时从入口引入跨电极卷积信息；融合 21 个电极后，再接后 5 层。用户进一步明确：第 5 层后的 21→1 融合特征，也分别跳接到第 6～10 个 Block 的末尾。

这是依据录音最终意见整理的方案，未修改仓库训练模型，也未进行训练或效果评估。录音里的“先写骨架运行”作为讨论内容记录，没有作为本次用户要求额外执行。

## 录音最终收敛的结构

| 部位 | 旧图 / 现有代码 | 最终方案及录音依据 |
| --- | --- | --- |
| 域分路 | Time 与 FFT 两路 | 两路保留；“一个分支”理解为每域只保留一条深度链，不是删除 FFT。 |
| 并行深度 | 每域 11 / 10 / 8 三条链 | 每域只保留 depth=10；16:38–16:49、28:32–28:43。 |
| Stem 电极融合 | 第二个卷积用 `(21,1)` 核，把电极轴 21 压成 1 | 保留 21 到前 5 个 Block。图中将这次空间融合从 Stem 移走，保留时间 / 频率轴卷积、池化、投影与维度置换；19:19–24:38。 |
| 前 5 个 Block | 原来输入 `[B,N,40]`，已无显式电极维 | 输入 `[B,21,N,40]`，每个电极沿 N 轴做 Transformer；25:17–26:15。 |
| 中途融合 | 无这一阶段划分 | 第 5 个 Block 的末尾之后，跨电极卷积 21→1，再 squeeze，得到 `[B,N,40]`；26:15–26:54。 |
| 后 5 个 Block | 普通 Encoder | Block #6–#10 处理融合后的序列输入；用户补充：同一份 21→1 融合特征分别跳接到这 5 个 Block 的末尾。 |
| 新增旁路 | 无 | 在各域 Encoder 入口，卷积 21→21，结果分别跳接到前 5 个 Block 的末尾；27:08–27:51。两域旁路分别计算。 |
| 基础超参数 | 最佳实验有 Encoder dropout=0.85 等参数 | 先回到 EEG-Conformer 基线默认，深度 10 按导师明确要求单独覆盖；28:32–29:20。 |

“逐电极处理”指 Transformer 注意力分别沿每个电极的 token 序列计算。由于新增旁路引入了跨电极信息，不能再把前 5 层整体描述为完全没有电极间信息交换。

## 必须分清的维度

| 符号 / 数值 | 含义 |
| --- | --- |
| B | batch 大小 |
| C=21 | 21 个真实 EEG 电极通道 |
| L=1920 | 原图时域窗口的采样点数；这是原图示例，不是重新确定窗口策略。 |
| F=961 | 上述 1920 点实信号做 rFFT 后的频率点数 |
| N=122 / 58 | Time / FFT 各自的 patch token 数；FFT 的 N 沿频率轴，不应全部称为时间点。 |
| D=40 | 卷积滤波器 / 学习到的嵌入特征维；不与电极一一对应。 |

现有 `PatchEmbedding` 的 `Conv2d(40,40,(n_channels,1))` 执行了实际的电极融合。后面的 `squeeze(2)` 只去掉已为 1 的轴。因此只删除 squeeze 不能恢复电极维，必须处理前面的空间卷积。

保留原时间卷积和池化时：

```text
N = floor((L - 24 - 75) / 15) + 1
Time: L=1920 → N=122 → 122×40=4880
FFT:  L=961  → N=58  → 58×40=2320
双域特征拼接: 4880+2320=7200
```

## 为了画出可实现结构而采用的假设

1. **跳接先按相加画。** 设入口为 `X0`，`S=Conv_C_21to21(X0)`，前 5 层为 `Hi=Block_i(H_(i-1))+S`。用户补充的后 5 层跳接为：`F5=squeeze(Conv_C_21to1(H5))`，`Z5=F5`，`Zi=Block_i(Z_(i-1))+F5`（i=6…10）。两段均加在每个完整 Block 的末尾，即该 Block 自身注意力、FFN 和内部残差之后。同一份 `F5` 在后 5 层复用，21→1 融合卷积只计算一次。录音曾提过串联，图中仍按同形状相加表示；若用拼接，须明确拼接轴和后续投影。
2. **同域各电极共享每个 Block 的参数。** 可把 `[B,21,N,40]` 整理为 `[B×21,N,40]` 计算，然后还原。21 次处理不一定是 21 套模型；录音未明确共享与否。各层之间、Time 与 FFT 两域之间按原模型各用自己的参数。
3. **卷积只明确电极轴的输入 / 输出，不替导师定死核与分组。** 21→21 的旁路保持 N、D 不变；21→1 的中途融合也保持 N、D 不变。一种满足要求的实现是在 `[B,C,N,D]` 上使用 `Conv2d(21,21,1)` 与 `Conv2d(21,1,1)`，让每个 `(n,d)` 位置按电极通道线性混合。这种 1×1 卷积的 C 就是电极轴，和原 Stem 的 40 个特征图不是同一含义。具体卷积形式仍待实现确认。
4. **末端 Time / FFT 特征拼接沿用原图。** 两路 Flatten 后接一个 `7200→256→32→3` 分类头。这是根据原图和现有 `TimeFFTFusionConformer` 推导的保留方案，录音后半段没有重新规定末端双域融合方式。
5. **取消跨深度模块是结构上的推论。** 每域只剩一个深度后，旧 Cross-Depth QKV 没有多深度交互对象，现有校验也要求至少两个深度分支；三组深度分类头、softmax 深度权重和深度辅助损失随之去掉。最终分类损失为一个三分类交叉熵，类别是否加权、是否重采样、训练日程需另行确定。

## 基线默认值的来源与边界

以仓库 `EEG-Conformer/train_activity_loso.py` 的本地基线实现为依据：D=40、heads=5、FFN expansion=4、Stem / Encoder dropout=0.5、分类头 dropout=0.5/0.3、Adam lr=0.0002、betas=(0.5,0.999)。没有额外核对上游版本，不能将“本地基线默认”与所有上游版本默认视为完全一致。

本地 `DEFAULT_DEPTH=6`，与录音明确的 10 层不同；实际实现必须显式设为 10。旧实验的 `[11,10,8]`、Encoder dropout=0.85、Cross-Depth dropout、深度辅助损失权重等不能整组照搬。
